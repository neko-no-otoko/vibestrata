# VibeStrata

VibeStrata is an AI-native messaging concept where the chat background is a living, semantic canvas that evolves with the conversation.

## Run locally

```bash
npm start
```

Then open `http://localhost:3000`.

## What is in this repository

This repository now contains a runnable prototype for:

- On-device-like semantic extraction and vibe delta scoring (heuristic runtime).
- Hybrid generation flow simulation (instant local preview + async cloud completion stream).
- Live "Living Canvas" morph behavior with adaptive chat bubble legibility.
- Vibe History gallery entries for each generation event.
